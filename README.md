# WMB · Zemin360 Hackathon 2026

Evidence-based talent profiles and reasoned employer–candidate matching.

## Problem

Talent platforms run on self-declaration: CVs, tags and self-written skill lists. Employers write
vague requests ("we need a developer"), candidates answer with vague profiles, and matching is a score
nobody can explain. Zemin360 problem areas addressed: **Profile & Portfolio Accuracy**,
**Organization–Candidate Matching**, **Clear Definition of Needs**.

## Idea

- **Evidence, not claims.** A candidate connects a repository, a live product or delivered work.
  An agent analyses the evidence and produces a structured *competence card*.
- **Needs, not job ads.** An agent turns an organization's loosely written request into a
  structured *need card*.
- **Reasoned matching.** Cards are matched to cards, and every match carries its reasoning:
  *this person fits this need because this evidence exists.* Employers see why a candidate is
  proposed; candidates see why they were not.

## What we measure

- Accuracy of the competence card against the evidence
- Clarity of the need card (can a third party act on it?)
- Time from a stated need to the first meaningful interview
- How many of the first five proposed candidates turn into an interview
